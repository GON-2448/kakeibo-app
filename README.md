# 家計簿アプリ

Pythonで作成した、支出を管理するための家計簿アプリです。

## 機能

- 支出の登録（日付・項目・金額）
- 支出一覧の表示
- 支出合計金額の計算
- 月ごとの支出合計の計算
- カテゴリ別の支出合計の計算
- 登録した支出の削除
- 登録した支出の編集
- SQLiteを使ったデータの保存
- 入力内容のチェック

## 使用技術

- Python
- SQLite

## 実行方法

1. Pythonをインストールします。
2. `kakeibo.py` があるフォルダをターミナルで開きます。
3. 次のコマンドを実行します。

```bash
python kakeibo.py
```

## 作成目的

Pythonの学習を通じて、データベース操作や入力チェック、データの登録・編集・削除などの基本的なプログラミング技術を身につけるために作成しました。
